Inventory Manager

Track products, stock and sales with live charts. Works fully offline — your data stays on your computer.

Windows.zip · Windows 10/11 macOS.tar.gz · Apple Silicon Linux.tar.gz · 64-bit

How to run it

  1. Download the file for your system and unzip it.
  2. Open InventoryManager. A window appears and your browser opens the app automatically.
  3. Keep the window open while you work; close it to stop the app.

If your computer warns you

This app isn't code-signed yet, so Windows may show "Windows protected your PC" (click More info → Run anyway) and macOS may block it the first time (right-click the file → Open).
